# iPhone Duo 한글키보드

두 개의 원형 입력판에서 자음과 모음을 선택하고, 슬라이드로 글자를 바꾸는 iOS 커스텀 키보드입니다. 작은 외부 화면과 넓은 화면을 함께 고려합니다.

앱의 표시 이름은 **세 판**, Xcode 프로젝트와 빌드 대상 이름은 `ThreePad`입니다. 이 저장소에는 네이티브 iOS 구현과 자동 테스트를 제공합니다.

## 기능

- 자음·모음 원형 자판과 방향별 입력 안내
- 시작한 키를 유지하는 슬라이드 입력과 시작점 복귀 취소
- 한글 조합, 복합 모음, 조합 단계별 삭제
- 영어 QWERTY, 대문자, 넓은 화면의 좌우 분할 배치
- 숫자와 두 페이지의 특수문자, `~` 입력
- 화면 높이에 따른 자판 높이 조절과 최소 크기 보호
- 지우기 길게 누르기: 0.4초부터 반복, 2초부터 단어 단위 삭제
- iOS 26 이상에서 Liquid Glass 배경, 이전 버전에서 흐림 효과
- 앱 안의 연습 화면과 설치한 키보드를 확인하는 입력란

키보드는 전체 접근 권한을 요청하지 않습니다. 입력 내용을 저장하거나 서버로 보내는 기능은 없습니다. 연습 화면의 배경은 앱이 직접 그립니다.

## 빌드

macOS와 Xcode가 필요합니다. 배포 대상은 iOS 16 이상입니다. Liquid Glass API를 컴파일하려면 iOS 26 이상 SDK가 필요합니다. 현재 코드는 Xcode 27에서 빌드를 확인했습니다.

1. 저장소를 내려받고 `ios/ThreePad.xcodeproj`를 엽니다.
2. `ThreePad` Scheme과 시뮬레이터를 선택한 뒤 실행합니다.
3. 실제 아이폰에 설치하려면 아래 로컬 서명 설정을 추가합니다.

```sh
cp ios/Config/Local.xcconfig.example ios/Config/Local.xcconfig
```

`Local.xcconfig`에 본인의 개발 팀 ID와 고유한 Bundle ID를 설정합니다.

```xcconfig
DEVELOPMENT_TEAM = YOUR_TEAM_ID
BUNDLE_ID_PREFIX = com.yourname.ThreePad
```

앱과 키보드 확장은 같은 설정을 사용합니다. 확장의 Bundle ID에는 `.Keyboard`가 붙습니다. Xcode에 본인의 Apple 개발 계정을 로그인하고 자동 서명을 사용하세요. `Local.xcconfig`는 Git에서 제외됩니다.

설치 후 **설정 → 일반 → 키보드 → 키보드 → 새로운 키보드 추가 → 세 판**에서 활성화합니다. 입력 화면의 지구본 버튼으로 키보드를 선택합니다. 앱의 **설치한 키보드 테스트**에서도 확인할 수 있습니다.

서명 없이 시뮬레이터용으로 빌드하려면 다음 명령을 사용합니다.

```sh
xcodebuild -project ios/ThreePad.xcodeproj -scheme ThreePad \
  -configuration Debug -sdk iphonesimulator \
  -destination 'generic/platform=iOS Simulator' \
  CODE_SIGNING_ALLOWED=NO build
```

## 입력 방법

| 시작 키 | 탭 | 위 | 아래 | 왼쪽·오른쪽 |
|---|---|---|---|---|
| ㄱ | ㄱ | ㄲ | — | ㅋ |
| ㄴ | ㄴ | ㄸ | ㄷ | ㅌ |
| ㅁ | ㅁ | ㅃ | ㅂ | ㅍ |
| ㅇ | ㅇ | — | — | ㅎ |
| ㅈ | ㅈ | ㅉ | ~ | ㅊ |
| ㅅ | ㅅ | ㅆ | — | — |
| ㄹ | ㄹ | — | — | — |

모음은 키 주변의 안내를 따라 입력합니다. 예를 들어 `ㅣ`에서 위는 `ㅗ`, 아래는 `ㅜ`, 왼쪽은 `ㅓ`, 오른쪽은 `ㅏ`입니다. `ㅒ`는 `ㅑ` 다음 `ㅣ`, `ㅖ`는 `ㅕ` 다음 `ㅣ`로 입력합니다.

길게 밀어도 거리 때문에 취소되지 않습니다. 시작점으로 되돌아와 놓으면 취소합니다. 짧은 중간 거리나 배정되지 않은 방향은 입력하지 않을 수 있습니다.

작은 화면에서는 안내 행과 별도 기호 행을 숨깁니다. 기호는 `123`에서 입력할 수 있습니다. 자판 내용 높이는 최소 220pt, 하단 버튼 높이는 44pt를 기준으로 합니다. 작은 화면에서도 터치 영역을 확보하기 위해 높이 비율보다 최소 크기를 우선합니다.

지우기를 오래 누르면 공백으로 구분된 단어와 뒤쪽 공백을 묶어 삭제합니다. 한 번에 최대 32글자이며 줄바꿈은 별도로 삭제합니다. 손을 떼거나 버튼 밖으로 옮기면 반복을 중지합니다.

## 테스트와 구조

```sh
swift test --package-path ios
```

| 경로 | 내용 |
|---|---|
| `ios/Core` | 한글 조합, 입력 매핑, 제스처와 배치 계산 |
| `ios/DocumentBridge` | iOS 입력 문서와 조합 상태 연결 |
| `ios/SharedUI` | 앱과 확장이 공유하는 키보드 화면 |
| `ios/KeyboardExtension` | 설치해서 사용하는 키보드 확장 |
| `ios/App` | 연습 화면과 설치 안내 |
| `ios/Tests` | 조합·제스처·배치·문서 처리 테스트 |

Swift 파일을 추가하거나 프로젝트를 다시 만들 때는 다음 명령을 사용할 수 있습니다. 프로젝트 파일과 공유 Scheme을 다시 생성하므로 수동 프로젝트 변경이 있다면 먼저 보관하세요.

```sh
python3 ios/generate-project.py
```

## 현재 확인 범위

개발 중인 프로젝트입니다. 자동 테스트와 시뮬레이터·기기용 빌드를 확인했습니다. 화면 크기별 배치는 계산으로 검사하지만, 실제 손가락의 오타율을 보장하지는 않습니다. 앱마다 조합·줄바꿈 처리가 다를 수 있습니다. 햅틱, 첫 줄바꿈, 길게 누르기 삭제는 사용하는 기기와 앱에서 확인해 주세요.

비밀번호 입력란과 커스텀 키보드를 허용하지 않는 앱에서는 iOS 기본 키보드가 나타납니다. 키보드 확장은 iOS가 제공한 영역 안에서 동작합니다.
